# Мониторинг SEO ComplexMedia

Обновлено: 2026-08-01.

## Внутренний дашборд

- Локальный preview: `http://localhost:3001/seo-dashboard`.
- Страница закрыта HTTP Basic Auth, имеет `noindex, nofollow`, отсутствует в
  публичном меню и sitemap.
- Доступ задаётся только переменными окружения `SEO_DASHBOARD_USER` и
  `SEO_DASHBOARD_PASSWORD`; пароль в Git не хранится.
- Период выбирается календарями. Google Search Console читается через отдельный
  сервисный аккаунт, Яндекс Вебмастер и Метрика — через OAuth-токен только для чтения.
- Таблица содержит 30 запросов, отдельные позиции Google/Яндекса и изменения за
  день/неделю. «—» означает отсутствие подтверждённой позиции, а не позицию 0.
- Блок новых формулировок показывает только реальные запросы с показами, которых
  ещё нет в отслеживаемом ядре.

Переменные окружения:

- `GOOGLE_SEARCH_CONSOLE_CREDENTIALS_FILE` — путь к JSON-ключу вне репозитория;
- `GOOGLE_SEARCH_CONSOLE_SITE` — необязательно, по умолчанию `https://complexmedia.ru/`;
- `YANDEX_OAUTH_TOKEN` или `YANDEX_OAUTH_TOKEN_FILE` — общий read-only токен
  Вебмастера и Метрики либо путь к защищённому файлу с ним;
- `YANDEX_METRIKA_COUNTER_ID` — необязательно, по умолчанию `103776627`.
- `SEO_DASHBOARD_USER` и `SEO_DASHBOARD_PASSWORD` — обязательная HTTP Basic
  Auth для закрытого маршрута.

Для query analytics Яндекс дополнительно требует `webmaster:verify`. Это право
также позволяет добавлять сайты в Вебмастер, поэтому новый токен выпускается
только после отдельного согласия владельца.

  показы, клики, позиция и CTR по 30 целевым запросам.
- [Яндекс Вебмастер — поисковая статистика](https://webmaster.yandex.ru/site/https:complexmedia.ru:443/efficiency/statistics/):
  общая динамика показов и кликов в Яндексе.
- [Яндекс Метрика — источники трафика](https://metrika.yandex.ru/stat/sources?period=month&id=103776627):
  визиты и посетители из поисковых систем и других каналов.
- [Яндекс Метрика — цели](https://metrika.yandex.ru/stat/conversion_rate?id=103776627&period=month&goalsConversionViewKind=List):
  отправки формы и конверсия после production-деплоя события
  `contact_form_success`.

## Отслеживаемые группы запросов

- Внедрение ИИ: ИИ для бизнеса, внедрение ИИ в бизнес/компанию,
  ИИ-автоматизация, разработка ИИ-решений, ИИ-консалтинг.
- ИИ-агенты: ИИ-агенты для бизнеса, разработка и создание ИИ-агентов,
  заказать ИИ-агента.
- ИИ-чат-боты: чат-бот с искусственным интеллектом, создание и разработка
  ИИ-чат-бота, ИИ-чат-бот для бизнеса.
- Продажи: ИИ для отдела продаж, внедрение ИИ в продажи, автоматизация отдела
  продаж с ИИ.
- База знаний: корпоративная база знаний, создание и заказ корпоративной базы
  знаний.
- Руководитель: ИИ-ассистент, ИИ-помощник и личный ИИ-помощник руководителя.

## Еженедельная проверка

1. В Google и Яндексе выбрать последние 28 дней и сравнить с предыдущими
   28 днями.
2. Записать клики, показы, CTR и среднюю позицию по сайту и целевым запросам.
3. Проверить страницы, у которых растут показы, но CTR остаётся низким.
4. В Метрике записать поисковые визиты, посетителей и достижение цели формы.
5. Новые статьи выбирать по реальным запросам с показами, а не создавать
   страницы, дублирующие коммерческие услуги.

Ручная проверка выдачи не используется как основной показатель: результаты
зависят от региона, устройства и персонализации. Источник динамики — данные
по фактическим показам сайта из Search Console и Яндекс Вебмастера.
